# Security policy

Please report vulnerabilities privately through [GitHub's vulnerability reporting flow](https://github.com/stanleycyang/symtri/security/advisories/new). Include the affected route or component, reproduction steps, and impact. Do not post a public issue or exploit a production account or data set.

Supported versions are the current `main` branch and its production deployment. Older commits and forks are not maintained.

SYMTRI keeps credentials in Vercel environment variables. `.env.example` contains variable names only; never add real values, database dumps, or provider tokens to an issue or pull request.
